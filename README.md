# Chatbot-Program

The program simulates a basic chatbot called Magpie2 that responds to user input with simple, rule-based replies. It looks for keywords like “mother,” “dog,” “Mr.,” or “hungry” to generate specific responses and uses default or random replies when no keywords are found. The logic ensures keyword matches are standalone words, not parts of other words. A separate MagpieRunner2 class handles user interaction via the console, continuing the conversation until the user types “Bye.” Additionally, the StringExplorer class demonstrates common string methods in Java, such as indexOf, toLowerCase, trim, substring, and compareTo, helping users understand how string manipulation works.
